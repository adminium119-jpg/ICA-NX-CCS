## Diagnóstico operativo

El avance más firme es de ingeniería de coherencia y memoria bajo contratos acotados. El aprendizaje y la interpretación de lenguaje nuevo mantienen baja cobertura. Las cápsulas solo admiten los 336 IDs conocidos y correcciones acotadas. El mapa C/L1/P3 es experimental. La independencia aritmética se limita a fórmulas separadas para la misma especificación y comparte controles estructurales.

El perfil identificó replay, copias y JSON como costes importantes. Una lectura de estado materializado redujo la mediana local de 104,6 ms a 18,3 ms, con el cálculo pagado antes de leer. Esa prueba registró un pico de asignaciones Python algo mayor en la ruta materializada. La atribución a un cuello físico de memoria requiere contadores de tráfico y experimentos específicos.

Los backends actuales contrastan recorridos dispersos Python y SQL. La integración nativa de GraphBLAS, la FPGA, el rendimiento de millones de episodios y el despliegue móvil completo permanecen pendientes de prueba.
